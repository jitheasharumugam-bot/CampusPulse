# CampusPulse
### Smart Campus Issue Reporting and Tracking System

CampusPulse is a responsive web application designed to help students report campus-related issues and track their status.

## Features

- Submit campus-related issues.
- Automatic priority classification.
- Unique issue ID generation.
- Dashboard with issue statistics.
- Track Pending and Resolved issues.
- Search reported issues.
- Filter issues by status and priority.
- Delete reported issues.
- Display report date and time.
- Save issues using browser Local Storage.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub
- GitHub Pages

## How It Works

1. Students enter their name.
2. Select an issue category.
3. Describe the issue.
4. Submit the report.
5. CampusPulse generates an issue ID and assigns a priority.
6. Users can track, search, filter and update issue status.

## Project Limitation

This version uses browser Local Storage. Issue records are stored separately in each browser and are not shared between users.
